# D2C Analytics & Operations Dashboard

Multi-client D2C business management dashboard UI, built from the product SRS. This is the **UI/frontend layer** — screens are wired to a deterministic mock data layer so every view is fully interactive and populated, ready to swap in real integrations (Shopify, Meta Ads, Google Ads, shipping) later.

## Stack

- **React 19 + TypeScript + Vite**
- **Tailwind CSS v4** with a custom design token system (light/dark themes, OKLCH color scale)
- **Radix UI primitives** (dropdown, dialog, tabs, popover, tooltip, select, switch, checkbox) wrapped into a small local component library in `src/components/ui`
- **Recharts** for trend/area/bar charts
- **React Router v7**, route-level code-splitting via `React.lazy`

## What's implemented

- App shell: collapsible sidebar navigation, sticky topbar, client selector, date-range picker, notifications panel, mobile-responsive nav drawer
- **Dashboard** — KPI cards, performance trend chart, daily summary, attention alerts, payment/customer split, quick tasks
- **All Clients** — agency-level overview table with per-client health status
- **Shopify / Sales** — sales trend, top products, recent orders table with search
- **Operations & RTO** — delivery status funnel, RTO trend, state/courier breakdowns
- **Products** — product performance table with 12-week trend sparklines
- **Geography** — state/city breakdown with delivery & RTO metrics
- **Meta Ads** — campaign list + client/marketing feedback thread (campaign review & activity timeline)
- **Google Ads** — campaign performance table
- **Blended Marketing** — combined spend, blended ROAS/CAC/CPO, formula reference
- **Tasks** — CRM-style Kanban board (To Do / In Progress / Waiting / Completed)
- **Manage Clients** — client list, integrations, team & permissions, add-client dialog

All data is generated by a seeded pseudo-random mock layer in `src/data/mock.ts`, so numbers are stable across reloads but vary sensibly by client, date range, and metric.

## Getting started

```bash
npm install
npm run dev      # start local dev server
npm run build    # type-check + production build
npm run lint      # oxlint
```

## Project structure

```
src/
  components/
    layout/     # sidebar, topbar, client selector, notifications
    dashboard/  # KPI card, chart tooltip, status badges
    ui/         # design-system primitives (button, card, dialog, ...)
  data/         # types + mock data generators
  hooks/        # shared data-derivation hooks (period comparisons, metrics)
  lib/          # utils (formatting, date-range helpers)
  pages/        # one file per route
  store/        # app-wide context (selected client, theme, date range)
```
